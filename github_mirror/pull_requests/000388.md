# PR #388: [Stability] Fix memory leaks in ggml_bitnet_free

Identified a memory leak in the BitNet initialization logic where allocated scales were not being properly freed during cleanup.

The Issue: In both ARM and X86 branches of 'src/ggml-bitnet-lut.cpp', the calls to 'aligned_free' for 'bitnet_tensor_extras[i].scales' were commented out or missing. This led to persistent memory usage that grew with every re-initialization of the model.

The Fix:
- Re-activated and secured the 'aligned_free' calls for tensor scales in both 'ggml_bitnet_free' blocks.
- Added null checks before calling 'aligned_free' to ensure stability.
- Cleaned up adjacent code comments to maintain repository standards.

Impact: Resolves significant memory leaks, ensuring BitNet can be safely re-initialized in long-running processes or multiple sessions without exhausting system RAM.
