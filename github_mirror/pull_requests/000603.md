Fixes #602. The official bitnet-b1.58-2B-4T declares hidden_act: relu2 but neither converter writes <arch>.hidden_activation, so the runtime falls back to SiLU and produces wrong logits on every backend.

Writes add_hidden_act("relu2") in both converters.
