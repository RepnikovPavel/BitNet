### Summary

- Adds per-head entropy-based KV cache eviction that reduces memory usage by 2-5x with minimal quality loss (~96% exact match at 5x compression)
- Includes a Python calibration script that profiles attention entropy per head, plus a pre-generated config for `bitnet_b1_58-large`
- Minimal integration footprint: 4 lines of code to add to any llama.cpp-based inference loop

### Motivation

BitNet compresses weights to 1.58 bits, but KV cache activations remain in float16. For a 0.7B BitNet model, the KV cache is **68.6% of total memory** -- the dominant cost. This PR provides entropy-guided eviction that exploits BitNet's inherently focused attention patterns.

Key insight: 49.8% of BitNet attention heads are sink/focused (entropy < 1.5 bits) and need very few KV cache entries. By allocating cache proportionally to head entropy, we compress aggressively with minimal quality loss.

### Results

| Compression | `--kv-budget` | Quality (exact match) | KV Memory Saved |
|-------------|---------------|-----------------------|-----------------|
| 2x          | 0.5           | ~96.5%                | 50%             |
| 5x          | 0.2           | ~96%                  | 80%             |
| 10x         | 0.1           | ~96%                  | 90%             |

Total memory savings for BitNet-0.7B at 2048 context: 34% at 2x, 55% at 5x, 62% at 10x.

### How to Test

```bash
# 1. Calibrate (or use the included entropy_config.json)
python calibrate_entropy.py --model 1bitLLM/bitnet_b1_58-large --output entropy_config.json

# 2. Build (after adding CMake lines from README_ENTROPY_KV.md)
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

# 3. Run with 2x compression
./build/bin/llama-cli \
    -m models/bitnet_b1_58-large/ggml-model-i2_s.gguf \
    -p "The meaning of life is" -n 256 \
    --entropy-config entropy_config.json --kv-budget 0.5
```

### Design Notes

- **Zero runtime overhead for entropy measurement** -- entropy profiles are pre-computed during calibration
- **Position-level eviction** -- works within llama.cpp's flat KV cache (no restructuring needed)
- **Always preserves the attention sink** (position 0) -- removing it crashes quality from 69% to 6.6%
- **GQA support** -- handles grouped-query attention by taking max entropy across grouped query heads per KV head
- **No external dependencies** -- includes minimal JSON parser to avoid adding a library dependency
