## BitNet Studio

A complete fine-tuning toolkit for BitNet models, focused on Brazilian Portuguese tool-calling:

### Features
- **Fine-tuning scripts**: CPU, GPU (Falcon 10B), and Colab (one-click)
- **Datasets**: PT-BR tool-calling datasets (61, 162, 19 premium examples)
- **Pipeline**: `pipeline.sh` automates train → merge → quantize → test
- **Studio CLI**: `studio/cli.py` with export, server, training subcommands
- **Tool engine**: `studio/server/tool_engine.py` + MCP bridge
- **Web UI**: `studio/webui/index.html`
- **Test suite**: exhaustive adapter tests, step benchmarks

### Colab integration
- 4 Colab scripts (3B and 10B models), Jupyter notebooks
- Workarounds for Falcon3 tokenizer and HuggingFace cache issues
