BitNet.cpp Demo on Google Colab: CPU-based Testing

This PR introduces a demo for BitNet.cpp running on Google Colab's CPU environment. Key features:

1. Demonstrates BitNet.cpp capabilities on standard CPUs
2. Fully automated setup process
3. Designed for quick and easy testing

The demo showcases how BitNet.cpp can perform AI model inference on CPUs, making it accessible for devices without high-end GPUs.

Testing instructions and expected outputs are included in the demo notebook.
