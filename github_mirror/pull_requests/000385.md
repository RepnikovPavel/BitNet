# PR #385: [Critical] Fix heap buffer overflow in QLUT workspace allocation

- state: open
- author: @DT-Foss
- created_at: 2026-01-29T18:17:54Z
- updated_at: 2026-01-29T18:26:14Z

---

Detected a critical size mismatch between allocation (factor 11) and addressing (factor 16) in src/ggml-bitnet-lut.cpp.

The Issue: For a standard 4096² matrix, this results in an ~83MB out-of-bounds write, causing heap corruption.
The Fix: Aligned the allocation size calculation in wsize to match the offset used in lut_scales addressing (factor 16).
Verification: Validated with local reproduction script; overflow is resolved.
Code Base: Cleaned up comments and debug logs to meet senior standards.
