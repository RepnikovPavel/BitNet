# Add Metal Backend for Apple Silicon Inference

## Overview

This PR introduces a complete Metal (Apple GPU) backend for BitNet, enabling high-performance 1.58-bit quantized LLM inference on Apple Silicon devices (M1, M2, M3 series). This significantly expands BitNet's platform support to include macOS and provides substantial performance improvements over CPU-only inference.

## Motivation

BitNet currently provides excellent performance on x86_64 (AVX2), ARM64 (NEON), and CUDA platforms. However, there's no optimized backend for Apple Silicon Macs, which represent a significant portion of the developer and research community. This PR fills that gap with a production-ready Metal implementation.

## Key Features

### 🚀 Performance
- **Up to 24x faster** than CPU inference on Apple Silicon
- **900+ tokens/second** throughput on real models
- **256-thread optimized** compute kernel (32×8 threadgroup configuration)
- Tested and verified with **bitnet_b1_58-large** (435M parameters, 24 layers)

### 🔧 Implementation
- **Metal compute shaders** for int8×int2 matrix multiplication (BitNet's core operation)
- **PyTorch MPS integration** with graceful CPU fallback
- **Optimized memory layout** leveraging Apple Silicon unified memory architecture
- **2-bit weight packing** with on-the-fly decompression in GPU kernels
- **BFloat16 output** support for optimal GPU performance

### 📊 Testing & Validation
- **Comprehensive test suite** with 10+ test scripts
- **Cross-platform profiler** comparing CPU/Metal/CUDA performance
- **Real model validation** with full bitnet_b1_58-large architecture
- **Benchmarked configurations**: Batch sizes 1-16, sequences 1-512

## Performance Benchmarks

### Real Model: bitnet_b1_58-large (435M parameters)

| Configuration | CPU (tok/s) | Metal (tok/s) | Speedup | Latency |
|--------------|-------------|---------------|---------|---------|
| Single token (1×1) | 3.70 | 15.27 | **4.1x** | 65ms |
| Small prompt (1×128) | 34.60 | 721.48 | **20.9x** | 177ms |
| Medium prompt (1×256) | 36.01 | 831.71 | **23.1x** | 308ms |
| Batch-4 (4×128) | 37.46 | 909.71 | **24.3x** | 563ms |

### Technical Optimizations
- **Thread layout**: 32×8 = 256 threads per threadgroup (optimal for Apple GPU SIMD)
- **Memory coalescing**: Improved access patterns for weight matrices
- **Unified memory**: Zero-copy data transfer between CPU and GPU
- **SIMD groups**: Leveraging 32-thread SIMD units for reduction operations

## Usage

### Basic Usage
```python
from gpu.metal_kernels.model import Transformer, ModelArgs

# Enable Metal backend
args = ModelArgs(dim=2560, n_layers=30, use_kernel=True)
model = Transformer(args).to('mps')  # Automatically uses Metal on Apple Silicon

# Run inference
tokens = torch.randint(0, args.vocab_size, (1, 128), device='mps')
cache = make_cache(args, length=128, device='mps')
output = model(tokens, cache)
```

### Profiling
```bash
# Compare all backends
python utils/profile_inference.py --backend all --batch-sizes 1,8,16

# Verify installation
python utils/verify_metal_backend.py
```
