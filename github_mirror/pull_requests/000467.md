Hello!

This PR aims to provide Containerfiles for BitNet.

This container differs from https://github.com/microsoft/BitNet/pull/438 with the following feature set:

* Uses azurelinux3 base platform
* Multi-stage usage (Final image does not need gcc/cmake/make/etc)
* Packs reference model into `model` dir for runtime, generating a ready-to-use image
* Uses `setup_env` to compile everything needed as upstream goes by (Changes on setup_env and requirements.txt will reflect the image).

Also, this image support rootless and does not run as root by design. This image defaults endpoint to inference server, being more proper designed to use with API and embedded usage - as intended by this project.

This image also can be parametrized by environment variables as Follow:

* MODEL: path to gguf
* CONTEXT_WINDOW: Context window size
* N_PREDICT: Number of tokens to predict
* TEMPERATURE: Temperature for sampling
* LISTEN_HOST: Host to listen
* LISTEN_PORT: Port to listen

Number of threads are automatically detected using nproc, ignoring 2 processors to allow system to breath. All variables uses same defaults from `run_inference_server.py` except by LISTEN_HOST that is configured to `0.0.0.0.` since docker/kubernetes handles ports by themselves.
