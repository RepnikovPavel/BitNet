# PR #488: fix: move sys.exit(1) inside except block in run_command()

The `sys.exit(1)` was at the wrong indentation level, causing it to run unconditionally after every subprocess command - even when the command succeeded. This fix moves it inside the except block so it only runs when the command fails.

Fixes #447
