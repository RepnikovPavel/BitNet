When running the latest release using `git clone --recursive https://github.com/microsoft/BitNet.git` on a fresh Raspberry Pi OS install, after installing the dependencies and running `setup_env.py`, it fails to compile. 

The error was caused by the missing headers at `ggml-bitnet-lut.cpp` and `ggml-bitnet-mad.cpp`, located at src/ directory

Adding the following code to the beginning of both files solved the problem

`#include <stdlib.h>`
`#include <string.h>`

I don`t know if it`s a architecture related problem, or it the code wasn`t prepared to be build on POSIX systems, but this little modification solved the problem to me. 
Hope it helps other users facing the same problem!
