### Comment by @Benjamin-Wegener at 2025-08-24T17:26:26Z

A new GGML_OP (GGML_OP_BITNET_MUL_MAT) was added in ggml.h.
Every tensor in llama.cpp has an op field; when the graph is built, any
weight matrix that is BitNet-quantized (type GGML_TYPE_Q2_0, Q3_0,
etc.) is wrapped in a tensor whose op is set to GGML_OP_BITNET_MUL_MAT.
