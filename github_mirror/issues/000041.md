The difference in memory usage between the LLaMA LLM model and BitNet B1.58 doesn't seem as large as expected, even though they have the same number of parameters. If the LLaMA LLM uses 16-bit precision weights and BitNet uses 1.58-bit weights, the memory usage for LLaMA should be at least 8 times higher. Why is the difference in usage smaller?

### Comment by @sean-jang00 at 2024-10-20T05:33:03Z

I was only focusing on the weights, but I should also consider the memory space used for activations. Since the activations in BitNet B1.58 are 8-bit, the memory savings for internal activations will be limited to 2x. The KV cache is also 8-bit, so the memory savings in that area should also be calculated as 2x.
I would like the author to confirm my assumptions.

### Comment by @shumingma at 2024-10-21T08:58:47Z

The KV cache and the embeddings remain in full precision. For a smaller-size model, they take up a larger proportion of the memory.
