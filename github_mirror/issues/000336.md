### Comment by @shifulegend at 2026-07-05T00:41:32Z

Project Zero (https://github.com/shifulegend/project-zero) might be worth a look here. It's a separate BitNet b1.58 engine, but the ternary matmul kernel has a scalar C99 fallback (`src/math/ternary_matmul_scalar.c`) with no x86/ARM intrinsics - it's the tier below AVX2/NEON in the dispatch chain, so it should just build with plain GCC on RISC-V.

Haven't actually tested on RISC-V hardware, so treat that as unverified. But the code itself is plain C: no inline asm, no compiler-specific vector builtins in that path, just conditional add/subtract on int8 weights. Performance will be rough since the scalar path exists as a correctness baseline for testing the SIMD kernels against, not as a speed target - but it should at least get you a running model to build a RISC-V kernel on top of.
