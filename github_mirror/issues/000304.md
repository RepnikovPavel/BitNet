### Comment by @kebuhler at 2025-06-17T15:26:11Z

I was able to get this working by modifying `/gpu/bitnet_kernels/compile.sh`. I added -Xcompiler and removed -Xcudafe --diag_suppress=177 --compiler-options. Compiled with CUDA/12.5

compile.sh:
`nvcc -std=c++17 -Xcompiler -fPIC -lineinfo --shared bitnet_kernels.cu -lcuda -gencode=arch=compute_80,code=compute_80 -o libbitnet.so`
