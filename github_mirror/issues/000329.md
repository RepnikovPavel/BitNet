### Comment by @ArrivedAditya at 2025-09-21T12:53:33Z

Huggingface download cli doesn't update download bar in real time.
It will update it after certain percentage.
This was happend to me also when first time downloading the model through this.
So don't worry about that. It will takes time depending upon you download speed.

Alternate option is to download model through huggingface website through browser then move the model into models folder -> <model_name> folder.
