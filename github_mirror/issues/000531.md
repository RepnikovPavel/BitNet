### Feature Request: Create an official Discord server for the BitNet community

**Description**

Hi team,

BitNet b1.58 and bitnet.cpp are getting a lot of interest from the community, especially among people who run models on CPU, edge devices, and those who want to try Falcon3-10B 1.58-bit, other ternary models, Open WebUI integration, etc.

Right now there is **no official Discord server** from Microsoft.  
People are scattered across:
- GitHub Discussions
- r/LocalLLaMA
- random unofficial Discords (kyegomez, some YouTube creators, etc.)

It would be very helpful to have one **official Discord** where we can:
- Ask quick questions about building bitnet.cpp
- Share working GGUF files for new 1.58-bit models (Falcon, future bigger models, etc.)
- Discuss integration with Open WebUI, LM Studio, SillyTavern
- Report bugs and share performance results on different hardware
- Coordinate community contributions

Would Microsoft consider creating an official Discord server for the BitNet project?

Thank you!
