On the latest version of BitNet.cpp, a "-cnv" option was added.
However, this option cannot work correctly.

if you run "run_inference.py" with "-cnv" option is off, the following error is occured.

```bash
python run_inference.py --model /root/BitNet/models/Llama3-8B-1.58-100B-tokens/ggml-model-tl2.gguf --prompt 'AI is going to' --n-predict 128 --threads 32 --ctx-size 2048 --temperature 0.8
error: invalid argument:
Error occurred while running command: Command '['build/bin/llama-cli', '-m', '/root/BitNet/models/Llama3-8B-1.58-100B-tokens/ggml-model-tl2.gguf', '-n', '128', '-t', '32', '-p', 'AI is going to', '-ngl', '0', '-c', '2048', '--temp', '0.8', '-b', '1', '']' returned non-zero exit status 1.
```

I think the root cause of this issue is following line.

https://github.com/microsoft/BitNet/blob/33ceabed0b421409c42106fb041af2151c83ea06/run_inference.py#L34

I think we should implement like this...

```python
    command = [
        f'{main_path}',
        '-m', args.model,
        '-n', str(args.n_predict),
        '-t', str(args.threads),
        '-p', args.prompt,
        '-ngl', '0',
        '-c', str(args.ctx_size),
        '--temp', str(args.temperature),
        "-b", "1",
    ]
    command.extend("-cnv" if args.conversation else [])
```
