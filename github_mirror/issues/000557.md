Built a Debian package that runs BitNet b1.58 2B4T as a systemd service on Ubuntu 24.04.

**What it does:**
- `sudo apt install bitnet-server` from PPA
- OpenAI-compatible API on localhost:11435
- Socket activation: 112KB idle, starts on first request
- Auto-downloads model from HuggingFace
- Sandboxed (unprivileged user, systemd protections)

**PPA:** `ppa:satyajeet1827/bitnet-server`
